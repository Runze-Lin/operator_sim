# PR 冻结独立验证：Matmul、FA 最大误差归因

按各算子全部 10 个合格 PR shape 的 `|预测/PR CA−1|` 选取；DT 是历史配对，不是新独立样本。以下均为事后诊断；未重采、未改参数。精确 trace 路径、SHA、正确性、计时器和模型冻结值见[验证记录](sku/holdout.json)中对应 ID。

|最大误差样本|DT CA / PR CA（µs）|直接复用 DT 预测（对 PR）|v0.14 预测（对 PR）|分核实测 DT=PR|
|---|---:|---:|---:|---|
|Matmul `[M,N,K]=[1,128,128]`；`m_cal_decode`|3.356 / 3.138|3.370（+7.40%）|3.414（+8.80%）|2 AIC / 0 AIV|
|FA `[Q,KV,D,B,H]=[9,4096,64,1,1]`；`fa_9_4096_64_1_1`|18.226 / 16.880|18.256（+8.15%）|18.483（+9.50%）|1 AIC / 2 AIV|

**Matmul——误差主要发生在第一对数据读之前。** 两侧 `msopprof` 的安装包 `aclnnMatmul → MatMulV3` kernel 二进制哈希一致，均 1,786 条时间线事件；尾核均为 `core0.cubecore0`，只做一次 `[1,64,128]` MMAD。两块各实际产出 1×64，最大首读描述符均 16 KiB，结果校验无错。下表按全局最早指令到最后完成的核分段，五段之和即 CA 总时长。

|尾核阶段（µs）|DT 实测|PR 实测|冻结 PR 预测|
|---|---:|---:|---:|
|启动至发出第一对读|2.067|1.901|2.139|
|第一对读窗口|0.933|0.871|0.881|
|读完成至首 MMAD|0.071|0.071|0.066|
|MMAD 窗口|0.082|0.076|0.107|
|最后 MMAD 之后的尾段|0.203|0.219|0.221|

证实：首读前缀多算 0.238 µs，占总高估 0.276 µs 的 86%；实测 PR 前缀比 DT 短 0.165 µs。按活跃核数定价的共用前缀没有捕捉到这里的提前；直接复用 DT 虽也偏高，却没有再加上 +0.044 µs 的迁移增量。**不能仅凭此例确定变化来自哪个标量依赖或缓存层。**

**FA——测到的是发起提前、计算间隙缩短，未测到 Cube 算力提升。** `aclnnFlashAttentionScoreV2` 的 PR 安装包 kernel 为 `FlashAttentionScore_50348df09d0b3ee451d3693a6b2ab3f5_2328361008425599520_mix_aic`；DT `npusim` 仅记录 `entry_kernel_2050000040140220`，无二进制 SHA，不能声称双侧二进制相同。两边输出 576 元素均正确。以全局首条为 0，对 DT 指令数据库（1,650 tick/µs）和 PR `msopprof` 时间线分别取 MMAD 的最早发起与最晚完成：

|FA 阶段（µs）|DT|PR|PR−DT|
|---|---:|---:|---:|
|首条指令至第一次 MMAD|7.767|6.877|−0.890|
|第一次到最后一次 MMAD 的窗口|10.138|9.679|−0.459|
|最后 MMAD 至全局结束|0.321|0.324|+0.003|

两侧均发起 64 次 MMAD，其中显式维度 `[m,n,k]=[9,128,64]` 有 32 次、`[9,64,128]` 有 16 次，余下 16 次未报告维度；可验证 QK 分块宽度为 128。64 条 MMAD 的持续时间相加仅从 3.468 变为 3.464 µs（作为指令特征，不加到上表）。实际总时长变化 −1.346 µs，冻结模型却给 +0.227 µs；其参考 DT 本身只高估 0.030 µs。因此直接复用更准，是因为它避免了**方向相反**的迁移增量。两个采集器的事件展开不同，不比较其全量记录条数；已定位的首发和依赖间隙变化并不唯一指向 HBM、同步或标量发射，区分三者需要进一步证据。
