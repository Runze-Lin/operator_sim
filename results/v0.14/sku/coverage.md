# 独立集的工作量覆盖

每个算子都在实际进入 PR 误差表的十个不同 shape 内，按逻辑读+写字节数升序拆为较小、较大两半（各 5 个）。逻辑字节不等同于物理 DRAM 流量；此表只描述采样范围，不能证实数据量继续增大后一定线性。

| 算子 | 最小 → 最大逻辑 IO | 较小组：PR / 复用 DT WAPE | 较大组：PR / 复用 DT WAPE | AIC 和 AIV 均命中 |
|---|---|---|---|---|
| quant | `[1, 64]` 194 B → `[640, 4096]` 7,946,240 B | 6.81% / 10.91% | 4.30% / 8.50% | 10/10 |
| matmul | `[32, 64, 64]` 16,384 B → `[512, 512, 256]` 1,048,576 B | 4.89% / 4.67% | 3.86% / 4.96% | 7/10 |
| fa | `[17, 96, 64, 1, 1]` 30,016 B → `[9, 4096, 64, 1, 1]` 1,051,456 B | 5.29% / 5.19% | 8.18% / 7.36% | 10/10 |

## 保持其余维度不变的数据量对照

| 两个输入（其余属性相同） | 有用工作量倍数 | PR CA 时间倍数 | 冻结预测时间倍数 |
|---|---:|---:|---:|
| quant `[576, 4096]` → `[640, 4096]` | 1.111× | 1.054× | 1.064× |
| matmul `[256, 512, 256]` → `[512, 512, 256]` | 2.000× | 1.098× | 1.063× |
| fa `[128, 128, 64, 1, 1]` → `[129, 128, 64, 1, 1]` | 1.008× | 0.968× | 0.982× |

quant 使用工具记录的向量有用工作量；matmul 和 FA 使用有用 Cube 操作数。跨行分块和核数变化均可能使设备时间偏离工作量倍数。不能从这两个测量点确定跨分块的渐近斜率。

数据角色：此处 PR shape 均在模型冻结后首次采集；历史 DT 结果仅用于配对分解，不能计为 DT 的新独立验证。每个点使用其冻结前的 dtype/attrs、相同输入和对应历史 runner。库与开源家族的对应不能证明某个开源提交与二进制逐行一致。
