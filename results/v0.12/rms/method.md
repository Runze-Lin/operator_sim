# RMSNorm：把统计量写入提前，主输出跟在归一化之后

输入 contiguous BF16 `[T,D]`、BF16 `gamma[D]`、ε=10⁻⁶，输出 BF16 `y[T,D]` 与 FP32 `rstd[T]`。对每行，`rstd=1/sqrt(mean(x²)+ε)`，`y=x×rstd×gamma`。支持 T≤512、D≤8192 且 D 是 16 的倍数；校准针对 CANN 9.2.1、`aclnnRmsNorm` 通过安装包 ops-nn 调度的 `entry_kernel_1388`，950DT `_9582`、1.65 GHz。`operator_model.extensions.norm_addmm` 给出 NORMAL 候选路径，源代码的 tiling key 不充当安装包实测 kernel 身份。无板卡或后代验证。

1. **分核和 UB 切块。** 最重核处理 `R=ceil(T/64)` 行、活跃 AIV 为 `A=ceil(T/R)`；末核可能较短。BF16 行宽 `C=align(D,16)`；归约临时预算 `L=align(ceil(2^floor(log2(C−1))/64),32)` B；`U=floor((253952−1024−2048−2C)/(8C+12+L))` 是一个 UB 块最多容纳的行数。分子自 UB 容量扣除了 host/arch35 保留空间和 gamma；分母计输入输出双缓冲、标量及归约空间。按 U 拆 R 行，保留最后不满一块的行数。下述工作量 `w=n×ceil(D/128)` 表示一个 n 行块处理的向量组数，不是实测 ISA 指令数。
2. **排出四个时间点（以下全是 tick）。** 第一个块以统计量写入发起时刻 `s₁=0` 为相对原点；最初的归约发生在它之前，只占下文的总 SIMD 时间，不能隐藏当前输出。块 j 的 `rstd` 从 `sⱼ` 在途到 `eⱼ=sⱼ+335.89+117.02N`；`N=max(0,min(A,32/R)−1)min(1,A/32)` 是 128 B 有效邻接窗口内的统计量写入压力，32 来自 128/4。它不是已测的 cache line 宽度。归一化后主输出在 `yⱼ=sⱼ+75.46+6.0493wⱼ` 发起，到 `zⱼ=max(eⱼ,yⱼ+302.50+6.6102×(2Dnⱼ/1024))` 完成；括号中是该核该块 BF16 输出 KiB，前序统计量仍在途时完成顺序有约束。下一块的 `sⱼ₊₁=yⱼ+270.87+4.4906wⱼ₊₁`：上一块输出未完成时下一块也能做归约，不人为排队到全部写完。各常数是每块启动/基础延迟，工作量系数为 tick/向量组，写回系数为 tick/KiB 或 tick/有效相邻写者。
3. **只把露在外面的写回相加。** `P` 为所有 `[sⱼ,eⱼ]` 与 `[yⱼ,zⱼ]` 的区间并集。`S=b(H)+11.2877×R×ceil(D/128)` 是整个临界核 SIMD 的总活跃 tick；首次、扩核和热态截距分别 515.38、324.39、302.77 tick。给定 resident_aiv 按实际状态取截距，默认按 v0.10 的冻结先验加权。`O=min(S, length(P ∩ [0,y_last]))` 是被向量工作隐藏的写回，`E=(length(P)−O)/1650` 是暴露的 MTE3 微秒。此处将块间计算**近似为连续窗口**；并非每个 tick 都确实有 SIMD，末块 `y_last` 之后不再用下一块覆盖写回。最终时延是 `S/1650 + E + t_arrival + t_SCALAR + t_MTE2 + t_other`；后四项保留 v0.10 的临界核独占阶段模型和状态处理，不能和原始队列时间直接相加。

**参数怎么得到的。** `development-evidence.json` 是 43 个旧 shape 的临界核指令区间，拟合目标均为阶段或指令的 tick，没有拟合总时延。非负 soft-L1（转折 80 tick）：SIMD 总区间 43 项，统计量写入时长和两次写入的发起差各 44 项；主输出基础服务只用 17 项（结束比统计量晚 >16 tick 且无下一笔统计量在途），最长直接可辨识为 16 KiB。更大拷贝的无竞争服务时间是外推。后续归约用 42 个单块的 `max(0,SIMD−两次写入发起差)` 作代理，含非归一化开销，不是独立识别的第二块归约。单块模型与大块流水的可辨识性不同；验证须同时看总延迟、原始并集与重叠。成本为 O(块数 log 块数)，当前最多 3 块；在线无 trace、无优化器。

**可重算例。** `[512,4096]` 共 64 核、每核 8 行；容量 U=7，两个块为 `[7,1]`，对应 FP32 28/4 B、BF16 57344/8192 B。本模型的默认 `P=1788.45`、`O=1370.54` tick，故 `E=0.2533 µs`，`S=1.9575 µs`，总 4.9688 µs；旧数据库实际 `P=2230`、`O=1057`，故 `E=0.7109 µs`，总 4.8509 µs。v0.11 的 E=5.8253、总 10.1635 µs。这个点参与了开发：总延迟已接近，但写回仍少估 0.458 µs，部分由其他阶段高估抵消。
