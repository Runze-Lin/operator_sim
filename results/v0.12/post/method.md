# mHC Post：没有历史覆盖信息时的点估计

输入 `[T,N,D]` 表示 T 个 token、N 个残差流、D 列，当前只验证 BF16、N=4、`has_h_res=True`。CA 通过 CANN 9.2.1 的 `aclnnMhcPost` 调用已安装库的二进制，CPU 校验全部 `TND` 个输出元素；开源 ops-transformer 实现仅用于对应算子家族，未逐指令证明与已安装二进制同源。这里只估计从首条设备指令到最晚完成核末条指令的时间，不含宿主调用和采集耗时。

**1. 先确定一核做多少工作。** T<32 时切通道（`entry_kernel_5`）：从 J=1 起，若 `ceil(D/J)>256` 且 `TJ≤32`，令 J 翻倍。T≥32 时先切 token（`entry_kernel_6`），J=1。令 `W=ceil(T/64)`、`A=J ceil(T/W)`、`d=ceil(D/J)`，分别为关键核行数、活跃 AIV 数及每片列数。64 是此设备建模的 AIV 数；分核规则的适用范围由实际入口与活跃 AIV 核查，不是通用架构常数。

**2. 逐状态计算关键路径。** 传 `resident_aiv=H` 表示前序同流 Post 调用的活跃核数高水位，H=0 选首次（first）；0<H<A 选扩核（expand）；H≥A 选复用（reuse）。三种克服启动及搬入延迟的代价不同。H 是执行条件的代理，不能由它推断出缓存命中率。阶段 q∈{arrival、SCALAR、MTE2、SIMD、MTE3、other}，状态 z 的模型为

```
t(q,z)=b(q,z)+s(q)·X(q)+e(q)·(W−1)       L(z)=Σq t(q,z)       单位 µs
```

b 是每次该状态的固定暴露时间；SIMD 的 X=`W ceil(d/64) N(N+1)` 是以 64 列分组的混合工作，s 是每组工作对应的暴露微秒。逐 token 的 MTE2 的 X=`2WNd/1024` KiB，是每核 BF16 主张量读取代理，s 是每 KiB 暴露微秒；既不计所有辅助张量也不等于物理 DRAM 带宽。逐 token 的 SCALAR、MTE3 有每多处理一行的增量 e（µs/行）；未启用的斜率为零。安装包不提供全部微架构参数，以 43 个已通过输出归属检查的历史 shape 在每条分核路线上单独拟合各阶段：非负 soft-L1，尺度 0.1 µs。对关键核重叠区间按 SIMD→MTE3→MTE2→SCALAR 优先分摊；arrival 表示相对全核最早起点的延迟，other 是未覆盖的关键路径。b、s、e 是这种暴露时间的估计，不是各队列孤立占用时间。SIMD、搬运工作会一起增长，单位成本不能直接移植到 A7/A8。[阶段参数及各组状态数](profile.json)

**3. 缺少 H 时，按可识别性选点估计。** 切通道 J>1 的分支取 `l=min_z L(z)`、`u=max_z L(z)`，返回 `P=2lu/(l+u)`。因为对于候选耗时 t∈[l,u]，点 P 的最大相对误差出现在两端；令 `P/l−1=1−P/u` 就平衡了过估热态和低估首发的代价。这个区间来自三个条件预测，不是实际 CA 计时的保证范围或统计置信区间。没有假定三种状态等频，扩核点在两端之间。对外分阶段结果用权重 `l/(l+u)` 混入慢端阶段、其余权重给快端，使和恰好等于 P；它不是实际一次发射的流水。其余两组沿用状态频数加权中位数：分别对 J=1 的切通道、逐 token，在该路由的观察序列下最小化绝对耗时误差；其余形状若落在不同的启动次序上，仍可能有大误差。模型不会在后台跟踪或改变调用状态。使用 H 的估计是同一模型的条件模式，不与缺省点混在一个准确性口径。

**算例。** `[1,4,3456]`：J=16，W=1，A=16，d=216；SIMD 工作 `ceil(216/64)×4×5=80`。三种预测（首次/扩核/复用）分别 4.788/4.211/2.313 µs。缺省值 3.120 µs；提供 H=0 得 4.788 µs，H=8 得 4.211 µs，H=16 得 2.313 µs。本次真实首发 CA 为 4.797 µs，说明知道状态可以明显缩小误差。对于 `[256,4,1536]`，W=4，A=64，d=1536，SIMD 工作=1920，MTE2 主输入代理=48 KiB；默认和 H=64 均估 6.205 µs。大 T 且固定宽度/同一分支时，工作随每核行数阶梯增长；多分支混合、访存压力或重新分块时不保证全局线性。[冻结的逐形状计算](freeze.json)

在线查询只执行三态、六阶段常数规模循环和分核判断；参数首次从随包 JSON 载入，不读 trace，不训练。100 次/shape、不缓存预测的墙钟实测见[独立评估](diagnosis.md)。CANNBot 950 数据搬运机制卡用于限定暴露时序与真实带宽的区别，未用文档峰值填充实测参数。
