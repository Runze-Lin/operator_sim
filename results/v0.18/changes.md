# v0.18 两条 Vector 路线

Quant 重新估算同粒度 scale 写入的暴露时间，RMSNorm 在目标芯片上按实际核数重新分配行，并计算读、归约、写回的暴露窗口。参数来源及局限分别见 [Quant](quant-method.md) 和 [RMSNorm](rms-method.md)。

每条路线冻结后各用 10 个新 shape，同宿主测两端。各格为 WAPE / 最大绝对相对误差。

| 算子 | DT 旧 | DT 新 | PR 旧 | PR 新 | 倍速旧 | 倍速新 |
|---|---|---|---|---|---|---|
| DynamicMXQuant | 6.50% / 15.51% | 7.25% / 15.51% | 15.31% / 20.45% | 12.98% / 19.65% | 9.13% / 18.07% | 7.63% / 10.76% |
| RMSNorm | 23.66% / 37.39% | 27.20% / 35.01% | 24.53% / 89.17% | 18.16% / 27.20% | 17.23% / 55.41% | 8.12% / 31.68% |

隔离安装 wheel 后的 453 次预测，中位 0.199 ms、P95 0.640 ms、最大 9.294 ms，导入另计 39.62 ms。

CA 共 41 次尝试，历时 17.85 分钟，产生 16.19 GiB；原始 shape、数据角色及采集成本见[审计](sku/campaign-completion.json)。970DT 只有配置驱动的外推。[全量误差与逐例分析](../../docs/error-analysis.md)

Quant 在 10 个新 shape 上，PR WAPE 15.31% → 12.98%，DT 为 6.50% → 7.25%。同组直接把新版 DT resource 估计当作 PR 耗时的 WAPE 为 12.64%，仍略优于显式 PR 路线。RMSNorm 的默认未知驻留态 PR WAPE 为 18.16%，详见总误差分析中与隔离首次条件的同集对照。

原计划为 40 次双端启动；有 1 次追加物理尝试。原始超限记录与通过核验的重试分别计费，预测保持冻结。
