# RMSNorm 在不同核数上的本地工作与写回重叠

CANN 9.2.1 的 `aclnnRmsNorm`，主输入和 gamma 为 BF16，输出为 BF16 y 和 FP32 rstd。保留原有整行路径合同，(1≤T≤512)，通道 (D≤8192) 且可被 16 整除。用户传入每卡 shape [T,D]，可选该类 kernel 连续调度的前序 AIV 高水位 H。参考 DT 的默认 auto、显式 calibrated 保留原结果；三端同口径比较用 resource，非 DT 的 auto 使用该资源模型。它读取两个 DT 阶段参数文件，在目标上直接分核、规划 UB、重算每核 SIMD 和写回重叠。950PR 和 970 无专属参数。

## 为什么 [64,2048] 从 8.709 变为 3.645 µs

950DT 实开 64 核，每核 1 行；PR 有 56 个 AIV，库将 64 行按每核最多 2 行均匀连续分配，实际只用 32 个核。两端的最后完成核都有 3 条对齐读和 2 条对齐写。旧投影的报告核数已正确，但把按 DT 一行、64 个写者定价的写服务与 SIMD 再按两波的资源倍率缩放。rstd 的争用由实际写者和每个写者的行范围决定；每核第二行和第二次完整启动有不同成本。

| 临界核互斥窗口（µs） | DT CA | PR CA | v0.17 PR | v0.18 PR（未知 H） |
|---|---:|---:|---:|---:|
| 到达 | 0.675 | 0.404 | 0.493 | 0.024 |
| SCALAR | 1.805 | 1.757 | 1.613 | 1.339 |
| MTE2 | 0.54 | 0.796 | 1.310 | 0.718 |
| SIMD | 0.34 | 0.638 | 0.648 | 0.459 |
| MTE3 暴露 | 0.99 | 0.968 | 4.640 | 1.101 |
| 总设备窗口（含其余间隙） | 4.352 | 4.568 | 8.709 | 3.645 |

PR 写在途并集 1.3576 µs，其中 0.3891 µs 有 SIMD 同时工作，剩余 0.9685 µs。模型计算写在途 1.2674 µs、可隐藏 0.1662 µs、净 1.1011 µs。该例统计量相邻写者由 31 降至 15，解释了写回价格需要下降的方向。trace 可以确认两条输出指令在途重叠及实际核数，未识别 cache bank 或 HBM 的物理命中。零、扩展和热态的预测分别为 4.654、4.501 和 2.995 µs。相对于整窗，未知态仍低估约 20.2%；SCALAR 与启动到达的低估占主要部分。在新进程独立调用的采集合同下显式传 H=0 可复现第一种预测。

## 由输入到目标服务时间

1. 令 C 为目标 AIV 数，则 `W = ceil(T/C)` 是最忙核行数，`A = ceil(T/W)` 是有工作的核数。通道数向上补到 16 得到 d。f 取小于 d 的最大二次幂（等价于取不小于 d 的最小二次幂再除二），辅助项 `e = 32 ceil(ceil(f/64)/32)`。每个 UB tile 的最大行数 `n_max = floor((UB − 3072 − 2d)/(8d + 12 + e))`，不足一行直接报告该合同不支持。将 W 分成若干整块和一个尾块。DT [512,4096] 输出 7+1 行，换目标 UB 后会重新切分。
2. 每行有 `g = ceil(D/128)` 个向量工作组。令 `π = 1000 P₃₂ / (C × 频率_GHz)`（FP32 op/cycle/AIV），`r = π_DT / π`，其中 `π_DT = 27000 / (64 × 1.65)`。没有可比较的目标峰值时令 r=1。SIMD 周期 `S_z = s_z + 11.2877 W g r`，条件 z 对应首次、扩核、复用；截距 `s_z` 分别为 515.377、324.392、302.773 周期。工作项随每核算力，截距随时钟。写与算都由目标的实际 W 与 A 决定。
3. 统计写竞争以 128 B 区域内 FP32 行统计量的相邻写者为代理：`P = max(0, min(A,32/W) − 1) × min(1,A/32)`。一笔 rstd 写的服务 `335.886 + 117.018 P` 周期。同轮主输出可在其发起后 `75.458 + 6.0493 n g r` 周期发起，n 是本轮实际行数；自身服务 `302.496 + 6.6102 × 2Dn/1024` 周期。主输出完成不早于同轮 rstd 完成。显式 MTE3 速率覆盖这里的每 KiB 字节斜率，单位从每核 GB/s 除以 GHz 转换为 B/cycle。下一轮规约移动 `270.869 + 4.4906 n g r` 周期。对两笔写的开始、完成区间合并，得到写在途 (U)。(O) 取并集中早于最后一次主写发起的周期数；SIMD 净暴露外的写为 `U − min(O,S_z)`。两段均在目标上重新计算。
4. 到达、SCALAR、未归属间隙以及 MTE2 的暴露开销各有对应状态下的 DT 阶段截距，转为周期后按目标 GHz 定价。MTE2 指令会与其他队列重叠；DT 校准在原范围中没有辨识独立输入字节斜率。提供目标 MTE2 速率时，另用最忙核读取 (2D(W+1)) B 除以该端口 B/cycle 作为最低读需求。冷读写假设下，整卡读为 (2D(T+1)) B（x 与一份 gamma），写为 (2TD+4T) B；总字节除以共享 HBM/L2 较慢的 B/cycle，给出数据路径下界。只有超过当前读、算、净写之和的部分加入共享项。跨核重复 gamma 载入、实际 DRAM 命中和端口排队尚无独立计数。
5. 所有周期除以 `1000 × 频率_GHz` 得 µs，互斥阶段相加得到条件时间 `L_z`。已知 H=0 选首次，0<H<A 选扩核，H≥A 选复用。未知 H 时输出三态端点 `l = min`L_z`, h = max`L_z`` 的相对误差平衡值 `2lh/(l+h)`，阶段分别以 (h/(l+h)) 及 (l/(l+h)) 混合最快与最慢状态。这是确定性的单值损失选择，不能推出生产环境各状态出现频率；上层知道隔离首次时应保留 H=0。查询不会修改历史。

设备 [64,2048] 的 970 情景按 120 AIV 得 64 核各 1 行，估 4.369 µs。其写者的行几何与 950DT 相同，增加空闲核不会平摊这笔统计写，970 尚无目标 CA。

## 证据与评估角色

旧 DT 的独占阶段来自 [v0.10 逐阶段参数](../v0.10/wide/profile.json)；写服务、SIMD 服务和时间顺序来自 [v0.12 的 43 份 DT 临界核时间线](../v0.12/rms/profile.json)。旧 DT/PR 的 10 组配对数据用于诊断，误差包含采集运行状态差异，其中部分 DT 来自连续批次，PR 为逐进程隔离。按真实原始 DB/JSON 验证 SHA，并以尾核 `SIMD > MTE3 > MTE2 > SCALAR` 唯一归属时间，另报写在途和同步隐藏量。PR 10 个旧例的未知状态 WAPE 为 23.63%，v0.17 同集为 30.09%；给十个旧例都传入隔离首次条件时为 5.94%，后者仅是上下文敏感性分析。旧 DT 10 个训练/诊断样例资源模式未知状态 WAPE 为 21.36%。这些数值均为开发回放。在本机以同一 PR [64,2048] 的已载入配置重复调用公共 API 100 次，包含第一次模型参数加载，中位 0.099 ms、最大 3.120 ms。复核既有测量可在仓库根目录运行 `python development/validation/sku18/rms_evidence.py`，不会触发 CA。[逐点阶段、预测和指令指纹](rms-paired-phases.json) · [提取脚本](../../development/validation/sku18/rms_evidence.py) · [逐步算例生成](../../development/validation/sku18/rms_examples.py)
