## 长 Matmul 的可选资源排程

当目标分块允许 B 在每个 AIC 的 L1 常驻、M 有多波、K 页与缓冲容量满足条件时，调用 estimate_matmul_supply()，其余输入沿用默认 estimate()。选择只用 shape、dtype、布局与芯片配置。此表对两种选择使用完全相同的设备窗，包含开发回放；下方 JSON 逐形标出改变的输入。

| 芯片 | 改变的窗 / 全部窗 | 默认 WAPE / 最大 / 有符号偏差 | 采用常驻情景后的 WAPE / 最大 / 有符号偏差 |
|---|---:|---:|---:|
| 950DT | 3 / 61 | 10.16% / 31.99% / +9.14% | 3.66% / 29.01% / +2.44% |
| 950PR | 3 / 70 | 28.30% / 43.50% / +27.41% | 21.84% / 35.64% / +20.83% |

在 DT 的 B8×32Ki 窄投影中，常驻排程估 16,384 条 MMAD，与 CA 相符，默认路径为 8,192 条。常驻模型的 85.246 µs 比 CA 的 85.993 µs 快 0.87%；同形 PR 为 176.124 / 174.953 µs，慢 0.67%。权重复用和输出跨缓存的读写服务都随目标配置重算。更宽输出的 Kimi 实验仍采用普通波次模型。按此策略实际调两个公开入口（适用时只调常驻排程），131 个已载入模型参数的进程内调用 P95 为 0.595 ms，最大 0.859 ms。[常驻条件、流水与双端新形](../v0.30/matmul/report.md)

模型选择优先保留能解释 tile、流量与流水的策略。在这些证据和独立绝对误差相近时，系统仿真可以优先采用略快的可实现排程。若减少的时间需要改变内核、缓存前提或向量归并，应给出假设，再与当前安装库的校准值分别报告。970DT 的时延和未来实现都只有外推。
