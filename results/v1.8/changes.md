# v1.8 · Flash 候选 Indexer 与 Roofline 下界

**输入与工作量。** 复用同一批 950DT、128 Ki decode 的 27 个 rank-0 配置。旧混合后端的 51,100 个回退节点共 3,026.562 ms，Flash 候选消费者排首位。官方参考中层 20 按每块 8 个位置的最高分选块，固定纳入最新块；后续消费者先对所有 key 打分，再限制候选、选 top-512 并按位置排序。B1 target 共对 1,179,729 个 query-key 对打分；在点积前 gather 候选的另一个实现只需 147,421 对。系统仅捕获元张量。参考算法、显式库组件与部署时实际内核分别登记。[方法与算例](../../docs/examples/candidate-filtered-indexer.md)

**系统比较。** 旧混合的基线覆盖 37.14% 按原已定价节点耗时加权。以 v1.7 冻结包重跑并校验旧账单，使用相同输入图重跑新模型，发布逐项覆盖、target/draft/整轮时间及变化归因。整体覆盖升至 67.63%，Flash 从 21.93% 升至 88.15%。原 Roofline / v1.7 / v1.8 在 27 个任务单轮累计为 4,814.851 / 5,139.758 / 3,737.268 ms，54 个新增节点的融合时间全部为外推。[27 组三方对照](../../docs/system-candidate-comparison.md) · [原回退耗时排序](../../calibration/reference/system-v17-fallback.csv)

**单算子物理边界。** 逻辑张量流量与同窗物理片外流量分别报告。2,180 个归档窗口中有 281 个可核实稠密乘加下界，其中模型与 CA 低于下界的次数均为 0。69 个超过 100% 的逻辑系数均由逻辑访存主导。原融合消费者的 950DT/PR 整窗误差尚缺，970DT 为外推；本次没有重拟合其他已校准算子。[总误差](../../docs/error-analysis.md) · [物理与逻辑指标接口](../../docs/integration.md)
