# v1.12 · Flash A5 候选 Indexer 的跨核归并

本版使用相同的 PA_BBND MXFP4 发布内核。对一行拆给多个团队的路径，从 950DT 和 950PR 已有 trace 提取局部分片写回、开始归并、列表读、radix 选位和写回的阶段时间。用剩余工作和剩余团队划分满 tile，并按每轮最多七份新列表加一份上轮结果定价。短尾仍以完整 tile 权重近似。模型和两个新样本价格已在采集前冻结，Git 快照为 `fd35fa6`。[冻结输入与预算](../../calibration/candidate_indexer/v112_protocol.json) · [冻结预测](../../calibration/candidate_indexer/v112_frozen.json)

- 六个旧窗用于开发回放。DT 三窗 WAPE 从 40.34% 降至 10.21%，PR 从 36.30% 降至 8.21%。1Mi 满候选单行分别从低估 47.34% / 38.42% 改为低估 16.29% / 9.93%。已更正旧报告混用 PR 数值检查与计时进程的分核说明。其合格波形有 28 个 metadata worker、28 份部分列表、四轮归并；DT 是 32 份、五轮。两端单行快慢方向仍不一致。[分段开销与算例](../../docs/examples/flash-a5-qsli.md)
- 对齐三段 trace，DT/PR 原来少计的 10.240/8.104 µs 中，最晚局部写完至设备整窗结束占 4.783/3.953 µs，余下在首轮供数和局部打分/收尾。新模型将末段差距收窄为 0.726/0.601 µs。
- 同图重放全部 33 组请求。10 组 Flash 增加 3.696–4.928 ms，1Mi/B1 的总时间为 93.079391 s，4,096 行末块为 0.480550 s。该末块每个团队持有完整行，不触发此次单行分片归并调整。其余 23 组与同精度峰值价格无变化。1Mi 输入之后的 decode 超预置位置。[逐请求与采样说明](../../docs/context-sweep.md)
- 从源码目录外调用安装的 1.12.0 wheel。12 个设备/形状组合，各 25 次公开查询。各组合中位数 0.158–0.284 ms，含新进程首次查询的最大值 8.200 ms。[逐组合墙钟](query-cost.json)
- 两项新独立 CA 均通过所有输出位置及原生 MMAD/逐团队地址检查。PR 的 32-query 共享页单波：v1.11 / v1.12 / CA 为 87.557 / 93.039 / 59.568 µs，新模型高估 56.19%，较旧版变差。DT 的 64-query 行变页集两波：两版均为 146.518 µs，实测 80.133 µs，高估 82.84%。两次并行采集和导出分别约 13 分 21 秒、24 分 30 秒。缓存命中率和生产页局部性未测；原始 trace 保留在 git 外。[同集误差](evaluation.json)
- 用 DT 两波重复 64 次替换四个消费层，末块为 0.462707–0.464015 s（两种启动假设）；原 DT 共享页对照为 0.484277–0.486915 s。本次 Q32 的共享页单波比 Q64 的行变页两波耗时更长，不能用差分来确定稳定增量。0.480550 s 属于同图粗估，PR 的误差不能用于标定 DT 的末块。[同图重放](../../calibration/candidate_indexer/v112_context_multiwave.csv)
