# v0.16 · 按目标芯片的资源给 tile 计时

Quant、Matmul、FA 新增直接按目标资源估时的路径。目标核数和片上容量决定分核及 tile；每个 tile 按指令分组、填充后计算量、各级字节量，以及资源发起和缓冲依赖求时间。在线预测不用同 shape 的 DT 耗时，也不用目标 SKU 专属的校准记录。模型只从 DT 旧 trace 提取阶段价格，Quant 13 个 shape、Matmul 17 个、FA 10 个。950 库的分块认识曾受旧 PR 数据检验。其他算子继续走已有阶段投影。目标资料不足时仍要假设有效带宽、延迟、同步周期及实现策略可迁移。[整套建模方法](../../docs/modeling-strategy.md)

## 冻结后独立验证

每项 10 个新的 950PR shape。表内各列使用同一批实际库 kernel 的完整 CA 时间，WAPE 为绝对误差之和除以实测耗时之和。

| 算子 | 新目标资源模型 WAPE / 最大 | v0.15 隐去 PR 名称 WAPE | 直接复用 DT WAPE | v0.15 PR 专属校准 WAPE |
|---|---:|---:|---:|---:|
| DynamicMXQuant | 12.18% / 22.25% | 4.78% | 5.23% | 6.26% |
| Matmul | 27.57% / 97.55% | 65.10% | 55.92% | 4.20% |
| FA | 5.52% / 10.83% | 8.13% | 7.64% | 1.72% |

- **Quant** 准确率回退。最差的 `[288,7168]` 连首块的读写字节都对，但读延迟预测/实测为 3.539/2.839 µs，写回为 1.725/0.795 µs。向量窗口接近，分别为 1.151/1.176 µs。共享限额与局部速率共同参与定价；尚无可单独确定每级缓存命中和 MTE 吞吐的目标证据。`[768,4096]`、`[1024,4096]` 在正式解析完成前触及单例输出容量上限，依预登记顺序启用两个替补。最终 10 点都在一个 UB tile 内完成，PR 多 UB 准确性仍待独立验收。[临界核逐阶段数据](quant-pr-phases.json) · [两次未取得完整计时的多 UB 记录](sku/multiub-incomplete.json)
- **Matmul** 8 个单波样例的 WAPE 为 7.50%，2 个多波薄 K 样例为 95.58%。`[1024,2048,32]` 的库实现会重切尾部并与前一批计算重叠；`[1536,2048,16]` 连 56 条 MMAD 也数对了，逐波重复计价仍高估 97.55%。这两项区分了分块误差和跨波调度误差。[56 个输出块的归属](sku/1536-multiwave.json)
- **FA** 在冻结时未使用 PR 首发或稳态价格，整体低于旧资源投影和直接复用 DT 的误差。Q9、KV=32767 的首条 MMAD 晚估 0.776 µs，之后每个满块预测 0.5172 µs，实测 K/V 发起间隔约 0.5023/0.5024 µs。512 条 MMAD 全部数对，总耗时预测 76.377、实测 73.035 µs。PR 的 128k 至 512k 仍为外推。[32k 边界的指令与发起间隔](fa-pr-32k.json)

四并发采集 32 次，30 次通过完整输出和时间窗检查。墙钟 782.1 s（13.0 min），原始输出 8.26 GiB。可计量的 CPU 时间为 11.12 小时，两次中途终止的 CPU 时间缺失；这些尝试的墙钟和原始数据已计入。没有新增 DT CA。隔离安装 wheel 后在进程内测量 1,200 次，最慢 2.785 ms，首次包导入另计 14.475 ms。[采集成本](sku/campaign-cost.json) · [查询开销](wheel-check.json)

已知 PR 可显式使用 `timing_mode="calibrated"`；架构研究可在三项上统一选择 `resource`，或者在非 DT 配置上使用默认模式。当前证据支持比较资源假设、追踪阶段误差；跨代准确性尚需目标测量。[总误差与逐 shape 明细](../../docs/error-analysis.md) · [历史回放和瓶颈切换算例](resource-replay.md) · [冻结清单](sku/freeze.json)
