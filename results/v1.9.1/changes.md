# v1.9.1 · 系统 Roofline 的精度对齐

27 组原图全部重放。精细模型的 8 位权重展开和 FP32 重缩放此前共用 16 位 Vector 吞吐。现在按各自位宽定价，重复展开的面板只增加展开指令；有用工作与实际排程的分精度账单分别返回。8 位展开吞吐是代理，A8W4 token-scale 融合投影匹配的 CA 整窗仍为 N/A。

| 同一精度与执行引擎的逻辑峰值基准 | 2464.358 |

| v1.9.0 精细模型 | 3992.324 |

重算 2,180 个归档算子窗。对矩阵扩展另复核 DT/PR 原生 Mm/Addmm 及 BF16→FP32 Router 的 20 个整窗，相同输入与旧版的设备预测逐值一致。这是开发与原留出数据的回放。本轮新增 CA 与新独立窗口均为 0。970DT 为配置外推。系统 B64 输入上的两个实际 A8W4 投影合同各重复 200 次，绕过系统预测缓存，单次后端调用中位数分别为 0.165/0.176 ms，P95 为 0.183/0.190 ms，最大为 39.561/0.204 ms。首个合同出现宿主墙钟抖动，计时均含 Python 后端，不含 CA 和整网 DES。没有端到端真值，无法赋予端到端预测 WAPE。
