# 950PR 新独立验证与采集口径

正式的 20 例均由 CANN 9.2.1 的 `msopprof simulator --soc-version=Ascend950PR_957b` 采集。每类 10 个不同的逐卡 BF16 shape，冻结前已排除 v0.13 / v0.14 实跑的 PR 样例。采集前的三个预测分别来自 v0.15 PR 配置、v0.15 DT 配置直接复用、隔离安装的 v0.14 PR 配置。冻结后未更改参数。未使用替补。

- [预算与形状](budget.json)、[冻结值和哈希](freeze.json)、[逐点估计/实际 kernel/正确性/核心窗口](holdout.json)、[全部尝试](attempts.json)、[独立集开销](campaign-cost.json)、[独立反例与指令诊断](posthoc.md)。
- 官方 trace 按全核最大的退出时间减最小的进入时间计时；逐核跨度须与官方摘要的差不超过 0.03 µs 或 2% 中的较大者。检查唯一实际 kernel、精确运行时 SKU、PR 外存模型、输入形状、golden 完整输出及数值容差。FA 不验证辅助统计张量。
- 20 次正式采集共 452.93 秒墙钟（4 并发），累计 1,697.43 模拟进程秒 / 29,383.59 CPU 秒，原始产物 2,748,216,339 字节。量级较大的 Q9、32k FA 仍由官方完整计时，单例耗时 266.38 秒、742,245,911 字节。系统在线预测无需任何采集行为。
- 11 点可额外配对历史 DT CA（FA 7，Matmul 4），其余 9 点 DT CA 为 null。对全部 20 点均有独立取得的 DT **预测**基线。只在有两端 CA 的子集分解芯片切换的误差；DT 历史数据不是新的独立留出。
- 在正式冻结前，另用 v0.14 已有 Q9、KV=4096 同形检验原生 helper + PR 仿真 SKU 适配器。适配器只负责宿主查询的 SKU 选择，外存模型和实际 CA 核心另行核对。原生 helper 虽通过数值、运行时 SKU、LPDDR5、核心数检查，17.2224 µs 和官方 16.8800 µs 相差 2.0286%，第一枚 Cube 核的跨度也越界。按[事先登记的门限](preflight-gate.json)拒绝跨链路使用。[控制结果](preflight.json)内有逐核证据；其 75.06 秒墙钟 / 1,466.65 CPU 秒另计，不混入独立样例。
- 所有原始官方 trace 均原样保留在 `runs/sku15/`。名称 `official_full_compacted_after_parse` 指先完成官方全量采集，再从官方时间线提取精简的关键事件 SQLite（`landmarks.db`）；它不代表截短 trace、降低核覆盖，或以 helper 时间代替官方测量。完整原始 trace 及 SHA-256 是复核依据。
