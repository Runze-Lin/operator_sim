## 调用方能提供哪些信息

内置 `aclnnMhcPost` 连续 BF16、四路、有 residual。当前三维接口 `estimate('mhc_post',[T,4,D],chip=...)` 只用芯片、数据类型和形状，返回一个点以及 `projection['timing_diagnostics']['state_scenarios_us']` 和 `state_range_us`。将当前硬件可行的首次、扩核、普通复用和紧邻重复分别定价。热端覆盖了紧邻重复对输入首读、向量计算和输出写发起的影响。令 $l,h$ 分别为时延最小、最大的状态预测值，单位为 µs，则默认值 $p=2lh/(l+h)$ 使得 $p/l-1=1-p/h$。这个点平衡两端的相对损失。服务均值应从实际调度状态频率推导，调用方可向 `estimate_post_history(...).expected_us(...)` 提供自己的频率。在 239 个已测窗中，真实 CA 落入状态模型区间的分别为 DT 110/151、PR 63/88，其余有端点预测误差。该区间用于检查模型可以表达哪些状态。[状态预测实现](../../../operator_model/post_history.py)

有同流顺序时，系统对**已成功提交**的算子调用 `OperatorStream(chip).advance(...)`。当前芯片核数决定活跃 AIV、通道或 token 分核，目标 UB 决定每行片数。对于普通 token 单片，分别定价状态、四笔输入发起和读响应，再计算最晚写出。对于 token 分核、前一条同族也为 token 分核、当前换形、已知高水位覆盖当前 AIV、且当前每行恰有两个 UB 片的情况，第一对片先预取，后续片复用两片前的槽，上一笔写尚未退回时可准备下一片。核心递推为 $W_j=\max(W_{j-1}+I_j, W_{j-2}-L+A_j+C_j)$。$W$ 是写发起周期，$I$ 是受向量/读/写限制的相邻写间隔，$L$ 是槽可重用的提前量，$A$ 是当前输入就绪等待，$C$ 是到可写的计算和交接。36 个 FP32 算术操作/列的计算下界随目标单核算力变化，DMA 随片字节和目标 MTE/HBM/L2 变化。两槽排程在本轮没有新增周期参数。曾测的代表换形 `[121,4,1216] → [65,4,5120]` 在 DT/PR 上分别为模型 5.663/5.747、CA 5.433/5.538 µs。双片普通换形的开发数据仅一形双端；其新形另行冻结。[实际逐片图和参数来源](../../v0.30/post/report.md)

未知前缀用 `forget_history()`。仅有显式 AIV 高水位可以区分占用状态，判定两片或紧邻重复排程还需成功的前序形状和 kernel 身份。只预览或失败的调用均不会推进状态。要复现旧行为可用 v0.31 wheel；`experimental_post_fragments=False` 可单独关闭两片排程。

## 同一个输入的理论精度上限

对于同形实测 $y_i$ ，任意只依赖可见输入的模型都必须给同一个 $p$。以 $a=\min y_i,b=\max y_i$ 记该组两端，最优最坏相对误差是 $(b-a)/(b+a)$，取 $2ab/(a+b)$ 时达到。取每组中位数能将绝对误差之和最小化。要求所有窗最大误差不超过 50% 时，每组允许取值的交集为 $[0.5b,1.5a]$，非空时将各中位数截入其交集可得到此附加约束下的最佳 WAPE。以下 oracle 使用了同一批真实标签，仅衡量有限数据集上可能达到的理论下界；完全相同的形状权重也会因冷/热重复的次数而改变。

| 芯片与统计范围 | 窗 / 形状 | 理论最优 WAPE | 理论最优最坏误差 | 约束 max≤50% 后的最优 WAPE | WAPE≤25% 且 max≤50% 是否可行 |
|---|---:|---:|---:|---:|---|
| DT 全部历史窗 | 151 / 113 | 9.67% | 47.60% | 9.77% | 理论上可以 |
| PR 全部历史窗 | 88 / 56 | 15.68% | 47.76% | 15.80% | 理论上可以 |
| DT 严格同库同形冷/热配对 | 21 / 10 | 27.64% | 47.60% | 28.46% | 不可行 |
| PR 严格同库同形冷/热配对 | 22 / 10 | 28.81% | 47.76% | 29.43% | 不可行 |

全量中有许多每端只测过一次的形状，oracle 能对这样的形状回填唯一实测值，极大降低样本内 WAPE。严格同合同配对还核过相同的发布 kernel SHA，显示相同输入具有不同的真实时间。两套统计均保留，没有删掉未达标的组。[每形真实样本、中位数与 minimax 点](replay.json)

## shape-only 最差形状与四路写回

`[9,4,3840]` 在两端都是 36 个 AIV，每个切到 960 列。分支是安装包 `MhcPost_59130ccee6717ff2c0f15b485e731162_5`，校验了 138,240 个 BF16 输出。DT/PR 在普通复用时 CA 为 2.686/2.745 µs，紧邻重复变为 2.128/2.092 µs。后两者低于当前热端预测 2.627/2.647 µs；公共形状点分别为 3.480/3.501 µs。末核都属于先前已执行的物理核。DT 热端误差最大的阶段是第一次加载到发出第四路写，模型 1.251 µs，实测 0.861 µs。PR 对应 1.271/0.827 µs。[全形阶段与同流先后次序](../../v0.24/post/evaluation.json)

| DT 临界片宽 | 向量函数 / RV_VAXPY 事件 | 以首个 RV_VLD 为零的四次输出写发起 µs | 每对相邻写间隔，约 cycles |
|---:|---:|---|---:|
| 448 | 25 / 224 | 0.408、0.565、0.721、0.878 | 258 |
| 640 | 25 / 320 | 0.362、0.531、0.699、0.868 | 278 |
| 960 | 25 / 480 | 0.306、0.492、0.677、0.862 | 306 |

PR 三种片宽也分别是约 258、278、306 周期。每次写 2d 字节，$d$ 为片宽，后面的写随计算量增大推迟发起，但首次写相对首向量加载能更早发起；整段临界时延在 DT 上只从 0.876 变到 0.861 µs。原热态阶段将向量组数线性加到固定 body 上，遗漏了这样的重叠。在相反方向的冷端，`[2,4,448]` 从一核扩到四核时，最后完成者位于新物理核，DT/PR 分别晚约 1.458/1.534 µs 才进入，CA 5.349/5.339 µs 均超过该形现有上端 4.788/4.792 µs。[四笔写时间、原始 shard 哈希与临界核](wide-repeats.json) · [新物理核的到达时间](../../v0.24/post/topology.md)

利用 DT 另六个片宽 ≤448 的已测重复实例，离线建立四笔 MTE3 写的候选。发起间隔取三项最大值，即单路 FP32 运算时间、单路 $2d$ 字节服务时间以及固定发起周期加向量组价格。逐笔时间戳估出的固定价约 216 周期，每 64 列约 6 周期，末组非满的额外价约 3 周期；首笔准备和末笔响应分别从真实首写/末写测量中扣掉运算/字节服务，固定退休约 10 周期。该候选在 DT/PR 960 列的热端预测变为 2.248/2.253 µs。全量仅 shape 的开发回放改善至 DT 27.48% / 58.39%、PR 27.41% / 59.36%，最大误差出现在 `[1,4,192]`。950PR 和较宽 DT 样本在分析前已知，归入开发诊断。两端新形 `[13,4,3520]`、`[19,4,2720]` 的预测已先于回执冻结，沿用原有队列。达到验收和覆盖要求前，这项候选单独列示。[四写模型与新形冻结](channel-freeze.json) · [全量诊断](channel-diagnostic.json)

## 另一个库合同的 1024 行诊断：vLLM HcPost

`aclnnHcPost([1,1024,4,5120])` 的固定 4096 列 tile 与内置 Post 的均分 UB 片不同。DT 用 64 个 AIV 各跑 16 行，每行一片 4096 列、一片 1024 列；PR 用 56 核，其中 16 核各跑 19 行，其余 40 核各跑 18 行。已通过的同宽短例 `[1,3,4,5120]` 在 DT/PR 各用 3 核各一行，默认模型 5.084/5.136 µs，CA 5.122/5.024 µs，缺少长循环稳态。[原算例与独立小形](../../../docs/examples/hc_post_vllm.md)

在 DT 大形原始采集中，选物理核号 0、7、15、23、31 的两条 AIV，共十份已完成的核内分片。逐核检查 16 行，每行两笔系数读、两片的 x/四流 residual 读、四个 VF 命令与两笔输出写；32 笔写的长度逐次为 32768/8192 字节。第 3–16 行所有 140 个槽周转中，每片 x 在两片前的对应写发起后 2 周期发起，residual 比 x 晚 2 周期。第一片算术 VF 恒在输入就绪后 3 周期发起；尾片算术 VF 与上次转换尾部重叠 47 周期。时间均以 1.65 GHz 的本地周期记录。DT 的实际稳态相邻同片写发起间隔中位 3288.5 周期，公开模型 4292.9 周期。首片 residual 是 32768 B，稳态响应中位 1096.5 周期，原来的小形 DMA 价格给 2072.9 周期；尾片 8192 B 的响应中位 809.5 周期，小形价格给 1043.0 周期。没有外部总线/缓存命中计数，观测只能说明有效响应时间降低。[十个核的逐行输入/输出/VF 以及核内文件 SHA](hc-dt-rows.json)

诊断候选保留原始首两行填充，后续使用两个已实际确认的读载荷尺寸。按 $L=a+b\times\textrm{bytes}$ 单独估 x 与 residual 的周期价格，x 得到固定项 658 周期和 0.02417 周期/B，residual 为 713.83 周期和 0.01168 周期/B。各取两个实际尺寸的稳态响应中位数解出截距和斜率，未取整形时延参与拟合。旧模型的 VF、发起、写响应和核域参数继续使用；在目标核数和时钟上重算槽周转，再以 HBM/L2 全片下界检查。候选在 DT 每核的稳态行间隔为 3316.5 周期。PR 真值返回前已锁定同形预测。

| 1024 行 vLLM HcPost | 默认 µs | 稳态读候选 µs | CA 角色 |
|---|---:|---:|---|
| 950DT | 45.169 | 36.884 | 十个完整核的事件用于开发；全芯片 CA 为 N/A |
| 950PR | 52.850 | 42.790 | 已在 PR 结果前冻结，原 HBM 下界为 37.508 µs |
| 970DT | 24.696 | 20.899 | 外推 |
