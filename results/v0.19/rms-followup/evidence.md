# RMSNorm 双端独立首次控制阶段

第二次冻结只更改可从旧配对 trace 重现的两项首次发起价格。模型输入仍是每卡 shape、dtype 和目标配置，970DT 继承 DT，调用时无需 CA。首版与第二次冻结的独立数据各自保留，基于旧测量的这里属于开发分析。

## 同几何的对照

取 v0.18 的十对隔离首次 trace，另有 v0.17 [9,5120] 的隔离首次官方双端 trace。早期 DB/application batch 的冷、热顺序不同，未纳入配对估价。要求模型两端实际活动核数、每核行数、UB tile 列表相同，这样 11 对只余 7 对。所有双端 kernel 的 AICore 二进制 SHA 逐对相等。下表列 PR 减 DT 的周期，负数表示 PR 更早或更短。芯片时钟均为 1.65 GHz。

| T×D | 尾核独占 SCALAR | 尾核独占 MTE2 | 中位核 rstd 单笔完成时间 | 全片最早数据读发起 |
|---|---:|---:|---:|---:|
| 1×5504 | -180 | -122 | 0 | -194 |
| 3×7552 | -26 | 75 | 4 | 127 |
| 8×6016 | -478 | 51 | -141 | -246 |
| 18×6912 | -353 | -8 | -315 | -277 |
| 55×1728 | -366 | 259 | -128 | -118 |
| 65×2816 | -331 | 675 | -267 | 71 |
| 9×5120 | -408 | -16 | -151 | -322 |

SCALAR 是最后完成 AIV 的互斥控制窗口。在同一时刻按 SIMD、MTE3、MTE2、SCALAR 的顺序唯一归属。7/7 形状的 PR 此项更短，中位差 −353 周期。跨所有核分别找首条 x/gamma 搬入数据的发起（去除 tiling 头），中位差 −194 周期，其中 5/7 为负。这个窗口与尾核的 MTE2 请求服务是两个不同的量。相同工作下，最晚核的 MTE2 暴露有正有负，rstd 时长变化还受区段写者和谁最后完成影响。终止核实测净 MTE3 的 PR−DT 中位只有约 +0.008 µs。因此只配这两个首次启动成本，保留已有读写吞吐、rstd 邻居模型和热态公式。不同芯片 SCALAR 的差异同时包含该 CANN 运行器的启动效果，不能推导新代每核标量吞吐。

PR 的 `rms_first_scalar_cycles=2580.5` 来自 DT 的 2933.5−353，`rms_first_payload_cycles=2776` 来自 DT 的 2970−194。目标可以独立覆盖任一字段。设 L 是原来除 shared_io 外的所有首次阶段（单位 µs），f 为 GHz，Q 为逻辑冷流量按目标配置共享带宽计价的周期。替换 SCALAR 后 L′=L+(新−旧 SCALAR 周期)/(1000f)，新的全核时间为 max(L′,(新输入发起周期+Q)/(1000f))。若调用传入了扩核或复用状态，仍返回该状态原来的估计；首次反事实一栏同时展示更新后的价格。

## 留一 shape 检查与局限

逐次留出一个旧 shape，只在剩下满足配对条件的 shape（6 或 7 个）上重新取两个阶段中位差，重算该旧输入。无目标整窗计价回归。11 组的方向正确 4→9；仅原 v0.18 十例为 4→8。仅同几何 7 例为 1→6。留一重估只校验这两个新增价格，早期 DT 参数本身已观察过 v0.18；这些数值属于开发回放。

| v0.18 旧十例留一 | 首次冻结 WAPE / 最大 | 目标首启参数 WAPE / 最大 |
|---|---:|---:|
| DT 耗时 | 3.11% / 7.79% | 3.11% / 7.79% |
| PR 耗时 | 5.80% / 10.72% | 4.67% / 12.43% |
| DT/PR 加速比 | 5.30% / 13.08% | 3.85% / 15.29% |

十例合计比值从 1.013 变为 1.053，CA 1.033。绝对值和逐个大小关系分别检验，仍可能错判接近 1 的情况；最大误差上升说明有些 shape 的局部瓶颈仍未知。旧最大两个输入 [393,3840] 与 [511,3968] 的 x/γ/y/rstd 总逻辑量约 6.04/8.12 MB，均能放入任一片上 L2。归档材料含 UB→GM 和 GM→UB 描述符时刻，但未记录该次输出产生的 L2 写命中或最终 HBM 写回字节数。用 L2 容量覆盖输入不代表这些地址当时真的驻留，带宽窗口也不能唯一识别写回策略。此次不引入“输出驻留 L2”修正；大 prefill 下仍报冷流量假设及外推。
