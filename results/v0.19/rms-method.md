# RMSNorm 的启动、写者与长流水

CANN 9.2.1 的 ops-nn `aclnnRmsNorm`，BF16 x/gamma/y，FP32 rstd。每卡输入是连续矩阵 [T,D]。当前计价路径假设按末维做整行规约，两端旧官方 trace 的 kernel 名均可核查。预测过程中只读芯片配置及本地模型参数。

## 从旧 trace 重建启动与芯片差异

下表与本节回放复现第一次冻结。第二次冻结在同一分核和流水上进一步替换 PR 首次控制及首个输入发起价格，DT、970 和明确的扩核/热态保持原条件时间。[目标首启参数与七组收敛证据](rms-followup/evidence.md)

v0.18 的 10 个 shape 在 DT、PR 上都是独立进程内首次调用。旧版没收到常驻核数 H 时用冷、热条件时间的调和平均。这让两端的启动都偏低，偏低程度还随芯片的分核改变。例 [57,1536] 中 DT 用 57 核、PR 用 29 核，实际最晚完成核相对全片起点的到达为 0.435、0.097 µs。旧版未知态预算几乎没有到达错峰。大 shape 又受不同来源的偏差影响，在旧公式里，所有核读写共享 HBM 的时间必须完全位于尾核自己的 MTE2/SIMD/MTE3 窗内。其他核可在尾核仍执行 SCALAR 时复制数据；PR 上较低的 HBM 配置更容易触发旧公式叠加的等待。两种误差都可在阶段账本中观察。单靠总时长或输入尺寸不能反推出每次调用的驻留状态、缓存命中或终止核身份。

省略 H 表示独立首次调用假设，对应这批 CA 的采集合同。运行中若 H 已知，H=0 用首次，0<H<A 用扩核，H≥A 用热态。三态各自的时间和阶段均会随预测返回。v0.19 在旧十组上的合计 DT/PR 从 0.919 改为 1.013，CA 为 1.033；逐例 WAPE 变化如下。这里的 20 条时间线已经用于诊断。另 53 例历史 DT 批次中，遗漏 H 的真实复用组 WAPE 47.78%，传入 H 后为 10.80%。调用方需要将明确的调度上下文传给后端。

## 从 shape 到时间

1. 芯片有 C 个 AIV、频率 f GHz。令 W=⌈T/C⌉，A=⌈T/W⌉，分别表示临界核最多处理的行数和有工作的核数。令 d 为 D 对齐 16 后的列数，F 为小于 d 的最大二次幂，e=32⌈⌈F/64⌉/32⌉。一个 UB tile 的容量为 m=⌊(UB−3072−2d)/(8d+12+e)⌋ 行。3072 B 为两部分预留，2d B 给 gamma，分母表示行缓冲、行统计与规约辅助空间。m<1 时不可用。将 W 除以 m 得整轮数和尾行数，输入满足 16≤D≤8192 且 D 可被 16 整除。D=16 且每核超过 512 行会进入窄通道转置候选，当前路径返回 unsupported。T>512 用同一整行策略外推，库若改变分支要重新确认。
2. 每个向量组覆盖 128 列，G=W⌈D/128⌉。ρ 为参考单 AIV 每周期 FP32 吞吐除以目标同一量；从全卡 TOPS 乘 1000，除以核数和 GHz 得 op/cycle/AIV。首次、扩核、热态向量服务周期分别为 `(515.377, 324.392, 302.773)[状态] + 11.2877 Gρ`。该项继承 v0.12 DT 向量占用刻度，缺失目标吞吐时继承 ρ=1。
3. 当前芯片上，每行 rstd 写 4 B。按相邻行归属推得同一 128 B 区段预计有 N=max(0,min(A,32/W)−1) 个其他写者。每 tile 的统计量完成延迟 s=133+147.58824N 个周期。它是有效写者代理。一个写者时可直接测到指令完成延迟；实际物理仲裁区段仍未证实。对于含 n 行的 tile，先发 rstd，过 Δ=75.458+6.04932n⌈D/128⌉ρ 周期发主写，主写服务 y=302.496+16.01826×(2Dn/1024) 周期。该次主写完成时刻为 max(s,Δ+y)。下一轮还需 270.869+4.49056n⌈D/128⌉ρ 周期规约发起。将所有写的时间区间取并集 U，早于末轮主写发起的并集为 O；暴露写为 max(U−min(O,SIMD),每核总输出 KiB×写周期/KiB−SIMD)。有目标 MTE3 单核带宽时，实际斜率替换为 1024f/B₃ 周期/KiB，其中 B₃ 用 GB/s。
4. 首次到达为 14.625(A−1) 周期，首次独占 SCALAR 为 2933.5 周期，未归属小间隙为 6.30 周期。读启动 L=1388.654 周期，目标每 KiB 周期 c₂ 取 1024f/B₂ 或继承 DT 的 18.39635。令 k=2D min(m,W)/1024 为最前一轮的输入 KiB，K=2D(W+1)/1024 再计本核的 gamma 与全部行，R=L+c₂k；暴露读为 R+max(0,c₂K−R−SIMD)。这保留首轮数据依赖和本核端口需求，其余预取可被 SIMD 隐藏。扩核及热态继承对应 DT 到达、SCALAR 与读启动截距，其余字节和写者定价相同。一次多 tile 的 γ 只收费一份。返回的读写字节是逻辑量及描述符量，HBM 总线实际事务量未知。
5. 在 10 个旧 DT 的隔离核 trace 中，从全片首条指令到首个实际输入描述符发起的中位数为 2970 周期。设状态下的输入释放 S=2970×(该状态 SCALAR/2933.5)，热态比例为推断。设 B=min(HBM 带宽, 已知 L2 带宽)，单位 GB/s，冷数据路径需要的周期 Q=f[2D(T+1)+2DT+4T]/B。取 max(分阶段本地总周期, S+Q) 除以 1000f 得 µs。只有共享资源超过原全片窗口的部分会拉长时间，逻辑冷流量假设没有测到命中率或实际 HBM 利用率。小网格另受局部发起、每核端口与字节服务约束，同一 HBM 峰值不会均分给一两个核。
6. 多整轮时，用两轮相同 tile 的写并集差估计下一完整轮的增量，尾块单列。所有迭代数由目标 UB 与每核行数决定。超过 32 轮只返回整轮数、每整轮行数、尾块行数；定价最多物化三个 tile。长流水的启动费用只付一次，稳态耗时随输入字节及工作组数近似线性，分核与最后一轮产生台阶。在 8×32k token 整批假设下这可能达到每核上千轮；离开旧 trace 的一至两轮区间应标外推。

## 参数来源及可辨识范围

| 参数（单位） | 数据与估计方法 |
|---|---|
| 14.625 周期/额外活动 AIV | 9 个旧 DT 多核隔离调用，各自用最晚完成核的到达时刻除以 A−1 后取中位 |
| 2933.5、2970 周期 | 10 个隔离 DT trace 的互斥 SCALAR 及全片首笔有效数据读，分别取中位 |
| 1388.654 周期、18.39635 周期/KiB | 9 个旧 DT 单 tile x 描述符；相距较远的 KiB 对求完成延迟斜率中位，从 MTE2 窗扣除字节项得到启动中位 |
| 133 周期、147.58824 周期/邻居 | 8 笔 DT 单行单核统计写延迟中位。5 个 DT 多核单行样例各减单核延迟、除以其他近邻写者数，取中位 |
| 16.01826 周期/KiB | 28 笔 v0.12 DT 主输出在 rstd 之后至少 16 周期才结束，取差距较大的有效字节对估计完成价格 |
| UB、频率、共享带宽、AIV、Vector 吞吐 | 目标配置，可替换。未知 MTE2/3 价格沿用 DT。128 B 写者区域和 UB 容量模型沿用 v0.12；单片 CA 不能唯一分离缓存、仲裁、发射与流水拥塞 |
