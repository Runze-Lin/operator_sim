# DynamicMXQuant 的双槽预取与片外写回

输入为本卡连续 BF16 矩阵 [R,C]，以每 32 个元素一个 scale 的方式量化到 E4M3FN。CANN 9.2.1 中实际运行 aclnnDynamicMxQuant、DynamicMxQuant_bf16toe4m3_high_performance_33_mix_aiv。价格来自旧数据的指令事件。新 shape 根据目标芯片配置计算，无需在目标机器上运行 CANN。[双端流水算例和完整公式代入](../../docs/examples/quant.md)

## 为什么旧模型在 PR 上输给复用 DT

在 v0.18 的 10 个历史输入中，7 个小/中 shape 的 PR 都比 DT 快。6 例的活动核数相同或输出预测接近，但旧模型给两端相同的启动和首读周期；在同核数的 [55,1152]，首个有效读在 DT/PR 分别于 4626/4221 cycles 发起。全核最早事件建立统一时间原点，160 B 的 tiling 读已经排除。两端 CA 环境使用不同模拟内存配置，首读前还需处理相同 kernel 的控制指令。此差值包含 CA 的指令发起、等待与取数行为，归因到单个物理单元所需的独立测量仍欠缺。

3 个大输入的 PR 又确实比 DT 慢，但 v0.18 过度惩罚了较低的共享带宽。[448,6592] PR 一核的两笔 52,736 B 读相隔 695 cycles 就已发出。旧模型用全部活跃核均分带宽，约 3,480 cycles 才准发第二笔。同时将全部输出写回片外作为退休条件。在当时的留出集上，显式 PR 相比直接复用 DT 的绝对误差，在 [255,5440]、[448,6592]、[513,5504] 合计多 1.23 µs，抵消 [7,4480] 分核正确获得的 0.99 µs 改善。这些 shape 现为开发回放。

## 从分核到设备耗时

时间先计算为目标周期，再除以 1000 f 得到 µs，f 为 GHz。根据目标 AIV 容量和 UB 容量划二维矩形，将 UB 切为两个输入/输出槽。A 为实际活动核数，最重核承担 r×c，其 tile 为 h×w，a=RC/(rc) 为折合的满载核数。定义 H、Δ 为最早有效读的发起周期、整波有效读起点的估计跨度，批量路径 Δ=s log₂ A；有预取和无预取分别测 H。短 scale 的单块路径使用行列分核序给读起点分配 0…Δ 的秩，跨度采用该路径既有 s=148.43 cycles 估计。

- **读。** 一个 tile 读 x=2hw B。本地响应 Lₗ=L₀+x/bᵣ，发起间隔 I=x/bᵢ。bᵣ、bᵢ 分别为每核持续服务和提交下一描述符的字节/周期。B 是目标 HBM 和 L2 可用的较小整片字节/周期数，未知 L2 带宽时仅采用 HBM。最晚一批核的响应 L=max(Lₗ,xa/B−Δ)。相比首核，晚到的核提交前，同波读已可占用共享端口。单核允许多个在途读；整片搬运量在最后作总约束。
- **Vec。** n=⌈g/8⌉+⌈g/128⌉，g=h⌈w/32⌉ 表示有效组数。首个 SIMD 可执行的时刻相对发读为 max(F,L+d)，F 是前端准备预算，d 是等待数据后的最短依赖间隔。VF 计算持续 V₀+nκ/p，其中 κ 代表一轮等效峰值操作，p 为全片 16bit 向量 TOPS×1000/(AIV 总核数×GHz)。n 和 κ 是执行工作代理，因而不能直接当作发射指令数。流水分别追踪可提交读的时刻、当前 SIMD/写回的结束、前一块 SIMD/写回的结束。第 t 块可以预取，复用两块前的同一个槽则需等对应消费者释放。重复相同 tile 的依赖矩阵按幂快速复用，完整工作量保留。
- **写。** 本块 FP8 数据 y=hw B 和补偶数的尺度 z=2h⌈w/64⌉ B 有独立写描述符。批量路径 D=242.51+y/b𝓌 是数据完成时间，S=max(307+z/b𝓌,D+81)+(P−1)J 是 scale 写服务，W=max(D,1+S,(y+z)/b𝓌)。P 为同一对齐 32 B 区段的不同生产者数的最大值，J=344.75 cycles 表示共享区段上相邻在途请求完成的间隔。只给共享粒度付生产者竞争，这一局部等待上限可高于真实等待。当每核只有一个 tile、每个 scale 写不超过 32 B 且多个核共享时，枚举请求相对到达时间，单独推进每个共享区段的完成时刻，再用 61.50 cycles 的返回间隔推进共享请求，不把全片最拥挤区段直接配给临界核。来自 10 例 DT 短写的这两个周期值都是有效仲裁代理。[短写调度校准](../v0.18/quant-calibration.json)
- **整片约束。** 输入 X=2RC B，输出 Y=RC+2R⌈C/64⌉ B。留给脏输出的容量 U=max(0,L2容量−活跃输入槽位字节数)，活动输入量取全输入与 A×同时活跃的槽数×首块读字节的较小值。取 Ydirty=ρ min(Y,U)，HBM 的暴露写入是 Y−Ydirty。ρ 默认 1，可用 quant_output_retained_fraction=0 指定写穿。Q=max((X+Y−Ydirty)/B_HBM,(X+Y)/B_L2)，其中带宽为各自的全片 B/cycle。Qread=X/B+最后一块最小的 VF 与无竞争写回时长+d，因为最后到达输入还需被消费。批量的 T=(H+Δ+max(双槽本地流水,Q−Δ,Qread−Δ)+E)/(1000 f)，E 为排空。短写请求排程已经显式包含错峰，相应采用最早发读 H 作时间原点。模型既报告逻辑输出，也报告退休前已经暴露的片外输出估计。CA 的本地搬运完成记录没有给出真实 L2 命中或逐笔片外写回，因此应按系统的缓存策略改变 ρ 作敏感性分析。

## 旧数据回放

旧 v0.18 的 10 例，DT / PR / 倍速 WAPE 从 7.25% / 12.98% / 7.63% 变为 5.51% / 7.40% / 4.94%。直接用新 DT 预测 PR 的 WAPE 为 14.75%。另一组源自 v0.17 的 10 例，同样比较 v0.18 与 v0.19，DT 由 8.08% 升至 9.66%，PR 由 11.60% 降至 8.02%，倍速从 11.55% 降至 8.43%。小片段实际仲裁顺序、跨核到达和 LLC 是否真实接纳所有预测可驻留输出仍有误差。[逐例回放](quant-replay.json)

## 冻结后的新输入

10 个新 shape 在两端均获得完整数值校验、核身份和全核时间。PR 耗时 WAPE 从 v0.18 的 15.65% 降至 5.22%，直接复用本版 DT 预测 PR 为 15.21%。DT/PR 倍速 WAPE 从 9.72% 降至 3.86%。DT 耗时 WAPE 从 4.56% 增至 5.34%，最大误差从 11.04% 降至 9.78%。新模型的 DT 最大偏差出现在 [53,1984]，预测 5.066 µs、CA 5.616 µs。PR 的最大偏差出现在 [641,5120]，预测 7.813 µs、CA 9.092 µs。[两端逐例全窗口和预测](evaluation.json)

在十例中最宽的 [1023,7168] 上，DT 预测 9.272 µs、CA 9.311 µs，PR v0.18 预测 19.254 µs，v0.19 预测 14.026 µs，CA 14.080 µs，970DT 外推 6.713 µs。额外的 [2048,5120] 单独统计，DT 预测 10.606 µs、CA 11.364 µs，PR 预测 17.834 µs、CA 18.504 µs，970DT 外推 7.733 µs。两种输入的宽度、tile 形状和分块不同，两个完整窗口尚不能确定固定 hidden 的渐近斜率。[大 prefill 算例和适用边界](../../docs/examples/quant.md)
