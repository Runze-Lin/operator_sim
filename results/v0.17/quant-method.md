# DynamicMXQuant 的每请求读写价格

ops-nn 的实际调用是 aclnnDynamicMxQuant，输入 BF16，量化时末轴每 32 个元素一个 E8M0 scale，E4M3FN 每元素写一字节。模型继承目标核数和 UB 容量驱动的二维分核，读、算与写用两槽依赖排程。以下所有时延项先以目标周期计价，最后除以 1000f 得到微秒，f 单位 GHz。

设最忙核负责 r×c，当前块 h×w。整卡输入 R×C，A 表示实际 AIV 数，等效满载核数 a=RC/(rc)。数据读 x=2hw B，FP8 写 y=hw B，scale 写 g=h·ceil(w/32) B。令 B=min(片外带宽,L2 带宽)/f，单位整片 B/cycle，未给 L2 带宽时只采用片外上限。每块读就绪 L=max(L₀+x/bᵣ,xa/B)，读发起间隔 I=x/min(bᵢ,B/a)。L₀ 是首笔读的固定部分。所有核在拥塞端口传输本批数据时，单核首响应延迟可以与其他核传输重叠，取这两个完成条件的较大值。bᵣ=48.36 B/cycle/核，取已校准大请求中，扣去固定延迟后最快首笔的服务率；bᵢ=68.91 B/cycle/核取重复读发起的可达速率。

一块 FP8 数据写的服务时间 D=242.51+y/b𝓌，其中 b𝓌=92.03 B/cycle/核，从数据描述符的持续时间独立拟合。同时发起的 scale 写窗口 S=max(307+g/b𝓌,D+81)+130.87(P−1)log₂A。307 周期、81 周期分别来自无共享 scale 小请求及其在同一核晚于数据写完成的中位剩余周期。P 是同一 32 B 对齐 scale 区段最多由几个不同 AIV 写。把 scale 线性地址除以每行 scale 字节数，再按本次分核的行/列片找生产者，重合的生产者只数一次。130.87 周期是 DT 有共享样本的 scale 额外等待除以 (P−1)log₂A 的中位数。它表征随核数与片段化加重的等待；现有证据不能唯一判断是 bank、写粒度冲突还是访存调度。P 是全图上界，临界核可能只经过较轻的竞争。

写窗口 W=max(D,1+S,(y+g)/b𝓌)。1 周期是两描述符发起差的中位数。数据和 scale 可在途重叠，在消费者看到写完成前端口仍需接收总 payload。片外带宽统一在整算子的冷读写总量下界及读就绪约束中体现；写指令退休不要求其他所有核在同一时间付清统一均分的显存预算。

每块 VF 服务 V=850.52+5+nκ/p，其中 n=ceil(g/8)+ceil(g/128)，κ=3469.52 个等效峰值操作/轮，p 为目标 BF16 全芯片向量 TOPS×1000/(AIV 总数×GHz)，未知继承 DT 能力。这些有效量取自首 VF 到首写间隔和前驱就绪，不能解释为 ISA 数量。两槽调度以已用输入/输出的释放时刻约束第三块，设备时延为 (4746.54+139.47log₂A+max(UB 排程周期,全张量冷读写 B/B)+16)/(1000f)。整卡下界的分子是全张量 I/O 字节数，分母是整片 B/cycle。参数来自 13 个 DT shape、16 个 tile 的逐指令边界，PR 历史 trace 只作冻结后诊断。[DT 描述符校准证据](quant-dt-evidence.json) · [每请求参数](quant.json)

**大请求**。旧 PR [288,7168] 的 56 个工作核中，临界核一次读 73728 B。原读预测 3.539 µs，新模型 2.949 µs，CA 为 2.839 µs。数据写 CA 0.559 µs，scale 写 CA 0.795 µs，两者起点相差约 1 周期。整段旧预测 1.725 µs，新预测 0.439 µs，实测 0.795 µs。端到端旧预测 9.791 µs，新预测 7.917 µs，CA 为 8.009 µs。写窗的绝对误差仍有 0.356 µs。[同集实测阶段](quant-pr-replay.json)

**短片段**。旧 PR [7,320] 的关键核实际取 128 B 尾片，数据写 0.307 µs，scale 写 1.571 µs。模型按最忙核、最拥挤粒度组合取 P=7，写窗估计 2.010 µs；资源模型总估计从 4.540 增至 6.341 µs，超过 CA 5.042 µs。该例说明最大工作量的核与最晚完成的核并非必然相同。十个旧 PR shape 的同集 WAPE 从 12.18% 降至 8.93%，不计入本轮新留出。[冻结后旧样本回放](quant-pr-replay.json)
