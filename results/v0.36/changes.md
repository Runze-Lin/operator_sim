# 第一版收口记录

公开后端为 0.34.0，主验收数据使用 v0.35 快照。内置 mHC Post 的无状态入口按现状作为第一版已接受的限制。原有 25% WAPE 与 50% 最大误差阈值继续显示在总表中，接受该限制保留了用户对具体误差的可见性。此次收口仅调整交付说明和已有采集的分析。

| 验收项 | 快照结果 |
|---|---|
| 有双端计时的输入与计时口径 | 24 项，其中 23 项在两端同时达标；同一个算子可有多个口径。 |
| 内置 Post，仅 shape | DT WAPE / 最大 27.94% / 63.56%，PR 28.02% / 67.40%。 |
| 内置 Post，有序流 | 在相同窗口上，DT 8.38% / 45.13%，PR 6.83% / 31.78%。 |
| 其它证据边界 | RMSNorm compact CA 只有 DT，标准 msopprof 有双端。Kimi 的 UB 驻留 AttnResFwd prefill 还待合格整窗。 |
| 每条实现的大输入双端完整窗 | 6 / 21；单端整窗、下界、wrapper 和 970DT 外推分别展示。 |
| 进程内预测开销 | 安装版 3,958 次测量最大 18.382 ms。 |

同 shape 的扩核和复跑有不同的首写时刻，原始指令能定位发生差异的阶段。每卡每流保留调度顺序可以给出两个不同的预测。文档补入了 [2,4,448] 的双端实际数值和单点预测的误差下界。[总误差表](../../docs/error-analysis.md) · [逐算子方法](../../docs/modeling-strategy.md) · [Post 算例](../../docs/examples/mhc_post.md) · [大形逐项核验](../v0.35/large/report.md)

本次冻结快照中，两个入口的四个扩核和复跑点预测已经在隔离安装的 wheel 上从实际调度顺序复算。快照列出验收分母、两个实测不足的口径、逐窗指纹以及运行版本。[核对记录](scope-review.json)

两份已有大形采集另有补证。LightningIndexer 的 Q=1、8192 个候选 key 在 DT 有完整的 22.709 µs 指令窗，预测 21.871 µs；PR 仅有预测。Kimi Matmul [32760,256,512] 的 DT 在原有 120 分钟预算内启动全部 32 个预计 AIC，退出前缺少完整设备计时和输出，不能评分。两项均未增加同形双端覆盖。[Indexer 核验](large/report.md) · [Matmul 终态核验](matmul/report.md)
