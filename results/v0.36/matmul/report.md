DT 和 PR 的设备临时目录均已装载 `MatMulV3_ND_ND_ND_ND_BF16_BF16_BF16_BF16_high_performance_131074`，两份实际 ELF 的 SHA-256 与采前登记相等。DT 发出了 AIC 0–31 的全部启动事件；停止时这 32 个临时单核摘要全部为空，缺 TASK_DONE、完整指令分片及 8,386,560 个输出的 golden。已选中的常驻 B 内核族和 DT 发核数可用于验证派发。MMAD 形状、次数、最后波的行为及完整退休均待证。

从本次 DT 的 128 个 HBM 通道提取共同封口的 23 个 1 µs DFI 周期，逐通道核对命令累计、读写 beat 与字节。全部通道合计读取 **29,616,960 字节（28.25 MiB）**，写入 **0 字节**。对这个调用，逻辑输入 A、权重 B 和输出 C 分别占 33,546,240、262,144、16,773,120 字节。模型假设部分输出可留在 L2，在现有 DFI 前缀内没观测到片外写。这些计数缺设备核时钟对齐和张量地址，既无法判定所有 C 已写入 L2，也无法确认每核恰好读取一次 B。尚无证据据此调整跨芯片吞吐参数。

截至 2026-11-20 09:17 UTC，对保留的 `runs/matmul*/**/run.log` 中 M≥32,000 的 13 份同接口实跑进行检查。6 份带全输出与合并时间线，分别属于 Flash M=32,768 / 262,144 / 1,048,576 的双端，均有既有完整窗。其余 7 份当时都缺全输出与整片时间线。其中 Flash B8×64Ki、B8×256Ki 的 DT 仍未报 TASK_DONE。没有增加 CA 次数。完整设备窗需要所有活动核首发到最后异步描述符退休，有全输出核对；单一调度标记和内存计数只能作为诊断。[逐次证据、控制器计数与校验值](audit.json) · [复核脚本](../../../development/validation/mm36/diagnose.py) · [已有六个完整大形时间窗](../../v0.33/matmul/report.md)
