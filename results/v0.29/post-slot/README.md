# 最后一项 Post 的宿主机时

本调度控制仅适用于原登记最后一个 [23,4,1984] 的 950PR 端点。若原主管先启动，资源监督即退出。原规定为每端单次最多 600 秒、1 GiB，同一流运行首次和连续重复并核对全量数值和每核终点。设备 ELF、输入、冻结预测均继续按照原合同。[原冻结](../../v0.28/post/registration.json)

对应 DT 已实际占用 4,247.9 CPU 秒，约 152 秒墙钟，宿主亲和性先从 32 核扩大到 58、62，再到 80 核。监督器连续三个区间检查宿主利用率，末项以 nice 14 运行。被选入的物理核每个区间忙碌率须 ≤35%，避开其它活跃进程的固定 CPU 掩码和重负载运行位置，可分配至少 56 个实际物理核，且整机还保留至少 24 个低忙核，才接手。若未实际移交，本页描述的是备用调度条件。
