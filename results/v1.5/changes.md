# v1.5 · 纯 Roofline 对照与 128Ki decode 算子覆盖

面向系统模拟器新增 `Estimate.rates["roofline"]`。它按芯片的分精度 Cube、Vector 峰值和 HBM 带宽计算理想窗口，再除以同形模型设备耗时。33 个输入合同都可以在总表进入逐窗明细。同一模式复算此前的 2,076 个合同窗，原有双端和 970DT 预测同值。[全量方法](../../docs/modeling-strategy.md) · [误差与利用率](../../docs/error-analysis.md)

| 新的本卡调用 | 依据与变化 | 独立设备验证 |
|---|---|---|
| BF16 → MXFP4/E8M0 动态量化 | host 的行列分块、双槽 UB、FP4 内层操作、两路写回。启动与传输价格沿用 950 量化校准。显式非连续输入只返回工作量 | DT / PR 各 4 个独立连续 shape，WAPE 7.14% / 8.87%，最大 15.26% / 18.66%。v1.4 没有该精度的预测 |
| 候选索引、两种 cache 物化、路由 A4W4 专家单投影 | 按候选覆盖的 key 数、cache 编码、有效专家行数推导工作量和逻辑字节 | 0 个设备完整窗，误差 N/A；专家投影回放了 3,582 次真实捕获的输入 |
| 三模型 decode 缺口 | 27 次运行核对 171,232 个 rank-0 节点、80 个原始调用名。FP4 量化出现 135 个几何，14,400 次连续，3,348 次为非连续视图。与现有双端 CA 维度和布局吻合的连续调用有 1,245 次 | 系统导出用于检查 shape/布局与确定优先级；CA 总窗独立统计 |

两次冻结均早于各自采集；收据中的版本字段沿用当时预发布源码的 1.4.0，源码指纹、冻结预测和逐核退休时刻保存在收据中。发布时重新核对了全部 2,084 个合同窗及 4,168 个设备预测。新量化 8 个 CA 进程墙钟合计 465.74 s，其中追加的 6 个使用两路并发，实际经过 272.21 s。新八窗归档的单次查询最大 5.005 ms（向上取整），全库归档查询 P95 为 3.231 ms、最大 18.910 ms。源码目录外安装 wheel，在三种芯片上核对四个新增公开入口和 Matmul；大输入 [64,131081,576] 量化的单次查询实测最大 0.764 ms。以上均为该主机样本，970DT 全部是外推。

窄尾块 [9,288] 的 2 B scale 描述符及只处理 32 列的末核解释了当前最大低估。非连续视图、全尺寸解压/回写、输出头分组的 A8W4 乘法等仍缺对应设备时延证据。[FP4 数值与指令](../../docs/examples/quant-mxfp4.md) · [135 个实际量化 shape](../../docs/system-quant-shapes.md) · [完整覆盖盘点](../../docs/system-workload-coverage.md)
