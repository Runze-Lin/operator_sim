# v0.13 芯片配置、工作量与双 SKU 校准

系统后端现接受独立芯片 JSON 和显式主输入 dtype。950DT 的机制参数按原库实现校准，工作量、芯片资源和执行调度分层。Vector、Cube、CV 按原有机制重新估算目标服务时间和重叠。DynamicMXQuant 用目标 Vector 核数与 UB 重选二维分块，Matmul 用目标 Cube 核数重新选输出块与尾波。返回 16 条路线的工作量口径、逻辑读写、估计吞吐，以及有依据的核数和阶段；KDA chunk 继续只提供结构指标。[全套方法与算例](../../docs/modeling-strategy.md) · [接口与芯片示例](../../docs/integration.md)

| PR 新采集 | 角色 | 预测 / CA µs | 有符号误差 | 预测与实测核数 |
|---|---|---:|---:|---|
| Quant [64,1024] | 开发 | 5.430 / 5.373 | +1.06% | 44 AIV |
| Matmul [128,256,512] | 开发 | 4.555 / 4.368 | +4.28% | 16 AIC |
| FA [16,64,64,1,1] | 开发 | 8.666 / 8.472 | +2.29% | 1 AIC、2 AIV |
| Quant [512,256] | 冻结独立 | 5.430 / 5.090 | +6.67% | 52 AIV |
| Matmul [129,256,256] | 冻结独立 | 3.987 / 3.609 | +10.47% | 20 AIC |

两种实现的重分块规则在新 PR 点命中了活跃核数。Quant 独立点触发参考模型的控制时间下限，直接复用 DT 时间预测也得到 5.430 µs。Matmul 独立点直接复用 DT 时间为 3.947 µs，更接近 PR CA。两个点支持迁移分核规则，目前不足以证明所有规模的耗时精度有所改善。FA 缺少 PR 独立样本。其他路线的 PR 时间，以及用户配置的 960 / 970 / 980 时间，均属外推。[逐算子误差与配对图](error-analysis.md)

DT 356 条已计时输入（含 152 条既有独立记录）的时间逐点复现 v0.12，沿用已有 DT trace。PR 新采集 5 个合格点共 298.8 进程秒、417.4 MiB 原始数据；额外 3 次基础环境通信失败共 206.3 秒，排除其结果。发布的 wheel 在隔离环境对两款芯片各回放 356 次，最慢分别为 2.596、0.770 ms，单独导入包 33.33 ms。[冻结数据](sku/holdout-freeze.json) · [安装验证](wheel-check.json) · [逐条工作量与预测](evaluation.json)
