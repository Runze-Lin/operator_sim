# v0.35 校准与大形验证

公开预测仍使用 0.34.0 安装版。v0.35 单独冻结了三个机制候选，在同一窗口与公开点估计对照。KDA 的验收保留 recurrent 单状态链、FLA V2，已移除的两条路线不进分母。[验收范围](../v0.33/acceptance-scope.json) · [全套建模方法](../../docs/modeling-strategy.md) · [全量误差表](../../docs/error-analysis.md)

| 算子 | 新证据和同集误差 |
|---|---|
| 内置 mHC Post，仅 shape | 239 个旧窗。双槽段把一次性首写与后续发起间隔分开，候选 DT WAPE/最大 27.24%/49.94%，PR 27.18%/48.62%；公开为 27.94%/63.56%、28.02%/67.40%。通道分核仍超 WAPE 门槛。 |
| vLLM HcPost | 从旧 PR 采集找回 1024×4×5120 的完整单 kernel，新增 CA 开销为零。公开 52.850 µs、CA 44.868 µs，在途冻结的 DT 读响应候选 42.790 µs。公开 PR 全档 WAPE/最大现为 8.49%/17.79%。DT 只具下界。 |
| DynamicMXQuant | B8 的量化混合内存服务直接取自有载控制器，B4 前 683 µs 的占比独立复现。对 B8×32Ki 的原生包络，公开 −32.52%，冷流候选 −1.36%。同一开发运行提供带宽标定。112 个小形指令窗的预测逐窗相同。 |
| MoE sigmoid TopK | 映射到安装库的 32 元组排序、四路归并与按 UB 容量分批。旧 22 窗 DT WAPE/最大由 7.72%/16.18% 到 5.75%/15.27%；PR 由 5.72%/11.02% 到 3.71%/6.39%。多批外推有待独立计时。 |

**独立验证。** 内置 Post 每端登记两种新 shape、各一次相邻重复，同进程四次调用。Gating 的 [1536,896,16] 在 950PR 的忙核跨 26+2 行的 UB 批界。Quant 的 [16384,7168] 复用已有双端采集预约及原设备验证。每项前置冻结和核验后的独立结果按芯片保留；仅有阶段流量、单端下界、在途盲评还是采前冻结都在专项数据中标注。970DT 均为情景外推。[Post 分组与下界](post/report.md) · [HcPost 单核完整性及图](hcpost/report.md) · [Quant 参数与算例](quant/report.md) · [Gating 分块与算例](gating/report.md)

**成本。** HcPost PR 检查已有 6.4 GB 全局 trace 及全部分片，用时 621 秒；B4 Quant 的 128 个通道离线解析用时 67 秒。这两次都没有重跑 CA。独立 Post 两端各限 40 分钟和 2 GiB。Quant 继续使用旧预算，每端最多 3 小时、64 GiB，同一物理槽最多执行一个 CA，排在 Post 新形之后。MoE Gating 复用已有槽。公开轮 3,958 次单算子进程内调用最大 18.382 ms；量化冷流和 mHC 候选的单次查询采样亦低于 100 ms。[公开查询成本](../v0.34/wheel-check.json) · [量化候选实测](quant/score.json) · [Post 候选实测](post/replay.json)

**复核与后续回执。** 总表合并上一轮逐形清单和本轮合格补充；同芯片、同合同、同 trace 指纹去重。可在未安装 CANN 的 Python 进程中从已经安装的 0.34.0 目录重算，命令为 `python3 -I development/validation/release35/score.py <安装目录>`。异步观察器只在输入收据变化时重算，数值失败、时间下界和没有闭合的内存前缀不会进入 WAPE。各大形沿用各自的设备合同和测量口径。[逐形补充](supplement.json) · [逐算子完整评分](acceptance.md) · [21 条路线的大形核验](large/report.md)
