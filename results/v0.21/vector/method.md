# 同一条缓存与搬运模型怎样用于 Cast 和 Sigmoid

这两条 950 AIV 内核顺序读取连续输入，将同样数量的元素写到另一段地址。模型先由 dtype 算读写字节，再由有效 AIV 数、UB 容量定分块，最后同时约束本核执行、所有核的并发发起和外存通道。目标芯片无需提供 CA 结果。

## 从逻辑字节到外存服务

令输入读量为 X、输出写量为 Y、可用独占 L2 容量为 L，单位都为 B。一次冷读、均匀顺序前进且没有其他工作占缓存时，末尾留在 L2 的 X、Y 地址占比近似为它们在这次流中各自的字节比例。

- 可保留的输出 D = min(L, X+Y) × Y/(X+Y)。
- 估计的外存流量 E = X + Y − D。前一项是冷读，Y−D 是未被缓存在结束窗口内的输出，反映写回压力。逻辑字节数 X、Y 保持独立返回。
- 对 A 个活跃 AIV，外存服务带宽 B = min(B_HBM, A × f × b)。f 为 GHz，b 为 B/周期/核，B 为十进制 GB/s。b 的缺省值为 30，以 950 的单核 MTE 时钟为参考。若显式给定单核 MTE2/3 带宽，则把 b 乘以两者相对参考值的较小比值，表示双向流均需发起资源。
- 整片共享服务周期为 H = max(f E/B, f (X+Y)/B_L2)。L2 带宽未知时只使用可辨识的外存项。实际总时间还受单核流水、首发和尾块约束。

**b 的可复核估算。** 950DT Cast 的 256ki×8 完整输入每个满块读 42,240 B，同一次 CA 的 128 个控制器记录总流量 312,226,048 B，全张量读量 X=134,217,728 B。末核满块发起间隔中位数为 1.9706 µs。在各核进度相近的稳态近似下，单核每个满块对应 42,240 × (312,226,048/X) B 外存服务。除以 1.9706 µs 与 1.65 GHz，得到约 30.2 B/周期/核。它是混合读写的有效发起率，包含银行仲裁、通道竞争及估算的分摊，不是公布的 MTE 指令峰值。把全窗口平均流量和末核中位间隔配对有系统误差；只在开发样本估算这一个常数。新卡可以显式给出 MTE 带宽并替换峰值/频率/并发核数。新卡的片上互联若有独立于 MTE 的变化，此假设需重新检查。[满块时间](../../v0.20/large/tile-intervals.json) · [同窗口控制器数据](../../v0.20/large/cast_2097152_32_Ascend950DT_9582-official-dram.json)

**物理交叉检查。** DT 256ki×8 Cast 的模型 E=298.67 MiB，控制器为 297.76 MiB。DT 128ki×8 Cast 的模型 106.67 MiB，实测 94.88 MiB；比例留驻不能恢复地址映射和替换次序。DT 256ki×8 Sigmoid 的模型 128 MiB；存档控制器最后采样为 126.14 MiB，采样与内核终点未精确对齐。PR 没有相同 DRAM 计数，其模型使用 112 MiB 缓存和 1.4 TB/s 配置；发布的逐样例误差保留该配置可能偏保守的影响。[Sigmoid 控制器快照](../../v0.20/newop/controller-snapshots.json)

## 如何把 H 放进流水

Cast 将终止核首轮的控制、读、转换、写按依赖相加，余下工作使用读、写、转换中最慢的单核资源，记为 P 周期。全核时间取 max(P, 1753 + H)/(1000f) µs。1753 是旧 DT trace 中从全核原点到最早数据读的周期数。图中按余下每块的工作量分配共享端口暴露的时间，展示这条吞吐约束等价的逐块位置，无法识别每一轮的实际错峰。

Sigmoid 在双缓冲的发起间隔中使用 H/N，N 为全张量元素数。对含 x 个元素的 tile，将 A x H/N 作为周期约束，只让本次整体的冷读及脏写参与通道竞争。单个 MTE2 的响应受局部延迟与当前冷读数据波次约束；MTE3 响应由片上写端口处理。整片共享服务和局部响应在流水中可重叠。[完整 Sigmoid 推导](../../../docs/examples/sigmoid_fp32.md) · [完整 Cast 推导](../../../docs/examples/cast_bf16_fp32.md)

冻结后新留出集每算子十个不同展平量，覆盖单核/分核、短 tile、局部多轮、缓存内外。两端都以真实 CANN API 和全输出金标获取整核窗口，比较 v0.20 与 v0.21 的同集预测。配置驱动的 970DT 数字始终为外推。本次范围是冷读、连续、独立 dispatch；存在融合、跨算子缓存竞争、输入已热或稀疏非连续布局时，物理流量将不同。[冻结清单](freeze.json) · [逐形状误差和样本角色](report.md)
