# v2.1　稠密 FA 的 Vector 定价试验

| BF16 开发回放 | 窗 | 原方法 WAPE / 最大 | 指令类别 WAPE / 最大 |
|---|---:|---:|---:|
| 950DT | 43 | 1.84% / 12.43% | 1.62% / 10.05% |

稠密 FA 可对同一 BF16 几何选择原模型或指令类别。FP16 和显式指定的按行设计默认采用类别法。两条路共享 host 策略与 Cube 定价。新模型分别定价行最大值、生成 P、行统计和输出更新，显式建模 P 可供 PV 的时间。另有受限的 950 双端读端口与首发交接探针。临时的测量目录和大型原始 trace 保存在版本库外。

冻结后采三个合格新窗，各次采集约 70–100 s。BF16 [9,4097,64,1,1] 的类别法单用在 DT、PR 分别高估 3.26%、9.52%，配探针后为 −0.30%、+0.22%。DT FP16 [9,257,64,1,1] 为 −1.54%。分类法在归档回放的两端查询 P95 均约 0.24 ms。970DT 仅外推。当前不扩大默认切换范围；32Ki 最忙核的模板服务与有效 RV 指令并集仍相差约三分之一。

使用同一包在仓库根目录执行 `python calibration/examples/compare_fa_vector_models.py replay` 可以重建开发回放、图和探针对照。开发回放的文件指纹包含 Python 包与复算脚本，独立验证单独保留采集前的实际报价和时间。冻结后增加了公共 API 的按行设计别名及包版本元数据，三次采集时所用的阶段定价和冻结报价保持可核对。
