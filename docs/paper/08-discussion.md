# 8　结论、适用边界与下一次最有价值的测量

## 8.1　目前能支持怎样的架构判断

在实现与工作分配可解释的路径上，抽取局部阶段参数能回答固定利用率难以回答的问题。量化例中的通道宽度决定有效分核与末核读写，矩阵乘例中的尾波与拆分决定第二波何时能使用资源，FA 例中长 KV 会反复放大几十个周期间隔的误差。三者共用从输入到任务、从资源到周期、从依赖到完成时间的顺序，各自保留与实现有关的工作单位。模型转移的对象正是这个顺序以及有证据支持的实现规则。

迁移证据有层次。原始指令可以直接确认一次发起、一个核的退休时刻、一次 MMAD 的形状；无法从一个总窗单独推回一个未观察到的带宽和另一个等待项。950DT 和 950PR 的并列试验能检查两套已知资源配置下的变化，部分路径含 PR 自己的服务项，应逐参数查来源。两张卡的核数、资源比和实现分支仍可能过于接近，不能覆盖 970DT 上所有新组合。第 5 章的资源替换与灵敏度试验给出可复核的方向、数量级和可能翻转的瓶颈。真正跨代误差仍待目标实现和参考结果。

在架构设计中，可先看影响最大的资源假设。若同一候选芯片上把一个继承参数放慢一倍，最关心的输出几乎不变，且没有跨过新的 tiling 分支，则当前方案排序对这项假设较稳健。若一次变动即可让两个候选芯片的先后顺序互换，应把方案列为待辨别，给出假设值和两种预测。遇到 UB、L1 容量阈值还需在阈值两侧分别计算；固定分块的局部导数反映不了新增一页、一次写回或一波任务的跳变。

## 8.2　剩余误差怎样切开

| 尚未识别的量 | 能区分原因的最小对照 | 结论可以推进到哪里 |
|---|---|---|
| A8W4 的宽投影在 PR 上多出的 4.82 µs | 固定精度、布局、K/N 和库入口，在相邻工作量下保存实际活动核、每核展开块、首末 MMAD 与最后写回；逐波对齐两种窗口 | 可逐项判断分核变化、展开过早串行或收尾过长，随后冻结并检验新形状 |
| mHC Post 同形状下的不同冷/热状态 | 同一 shape 用首次、重复和由小到大的有序流，记录启动至首条有效搬入和最后写回 | 可将不可见历史造成的散布与每元素服务误差分开 |
| Flash 各行候选页的并发影响 | 在 PR 上复用同一个二进制、shape 与逻辑字节，只改访问顺序，另保留未揭盲布局 | 可检查 DT 的趋势能否迁移；全调用仍需覆盖 metadata 前后处理 |
| 换代后未知的 Vector、MTE 和 UB | 选独立流测发起间隔、依赖链测响应，再用工作集分别落在两级容量两侧 | 能替换单核价格和容量分支，缩小第 5 章情景范围 |
| 完整物理 Roofline U | 在相同计时边界内采集 HBM 控制器读写字节、引擎类型与精度，再计算下界 | 可以判断物理超界；当前逻辑系数的解释仍需保留 |

这些对照的选择原则是“不同机制对实验的预测要不同”。例如给同一数据点再测十次可以估计波动，却不一定能区分首次读等待和稳态间隔；保持工作量不变而只改变轮数、页序或驻留条件，通常更能约束参数。在线接口应保留影响排程的元数据，特别是混合精度的 scale 轴、布局、专家 token 分布和前序信息；系统无法提供时，应输出所采用的假设。

## 8.3　交付给系统仿真的是什么

一次在线查询可以返回设备微秒、有用 Cube/Vector 工作、逻辑读写字节以及可识别的活动核和实现路径。接入系统时先检查结果状态和时间是否为空，再确定发起开销由哪层收取，最后交给事件排程器处理通信和不同流之间的约束。若只需要选芯片和并行策略，可以先用端到端敏感性筛出影响排序的少数合同，再投入昂贵的 CA 采集。逐形误差、全图覆盖与证据口径让模拟结果可以追溯到这一步决策。

本文最清晰的一条证据链是单头 FA。它从 DT 的 256 个 K/V 发起点出发，经每页工作量和间隔估计，走到 PR 的 512 页整窗，再走到 970DT 的假设资源。沿这条链，读者既能复算预测为何接近，也能看到它没有解释的一部分跨卡速度差。给出这个可检查的剩余误差，比单独给一个整网速度或一个利用率更有利于下一轮架构取舍。
