模型和 CA 均为设备微秒（µs）。有符号误差为 `100 × (模型 / CA − 1)`。等效 Roofline 利用率 U 为同一输入的理想时间除以模型设备时间。表内同时列出理想时间的控制项；合同汇总只对可比窗按 `Σ理想时间 / Σ模型时间` 聚合。查询列为归档 CPU 墙钟毫秒（ms），顺序为 950 / 970。970DT 的时间与 U 都是外推。
