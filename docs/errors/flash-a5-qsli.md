## 真正的 A5 融合 kernel

通过发布包的 `installed_hit` 验证相同的 PA_BBND / cmp_ratio=1 AOT，设备映像 SHA-256 为 `b3a854470fe46368ac752ccccd7ed0bb7ffb087b658373c2ac97bfce027ae4ff`。在 CA 中，AICPU 元数据任务报告 `unsupported task type: AICPU_D`。为计时融合内核，先在主机按发布的 metadata 算法取得并校验 1,024 个 int32 字，再在 CA 中执行原生 AOT、读取输出并检查全部 512 个全局位置。下表的 CA 值包括 kernel 内 gather、Cube、Vector 与所需的跨核归并。主机生成分核表的时间不计入设备窗。

|---|---|---:|---:|---:|
| 1、1、1,024 | 81 / 8 | 6.831 / 6.836 | 11.088 / 11.483 | −38.39% / −40.47% |
| 1、1、1,024 | 81 / 8,201 | 8.072 / 8.077 | 11.352 / 11.225 | −28.89% / −28.05% |

**列说明**　B 是 batch，Q 为每请求 query 数，L 是可见上下文。候选块/页表列均为个数。后面各列依次比较 DT、PR 的历史模型和原生融合 CA 整窗；误差为预测/实测减 1。

## 1Mi 满候选单行，默认分核

Q=1、L=1,048,576、c=2,048、页表 8,201 列，一行的 32 个 tile 分给多个团队。输入含 256 个有物理映射的候选页，跨度覆盖首尾，输出 512 个全局 ID 在两端均与 CPU 的 MXFP4/E8M0 golden 一致。每端收到 32 条 32×512×128 的 MMAD_MX。DT 32 个物理 AIC 各 1 条；PR 28 个物理 AIC 中 24 个各 1 条、4 个各 2 条。和这两份合格 trace 同次启动的 FIXTURE 日志记录 DT 32 个、PR 28 个 metadata worker。此前另一次 PR 数值检查曾报告 32；该次没有合格 trace。单个工作分片可以包含两个 tile，tile 数与待归并列表数须分开统计。
